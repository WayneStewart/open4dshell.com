# open4dshell.com

Source for the Open 4D Shell static site. Wayne Stewart's home for
open-source 4D components, starting with Foundation.

## Layout

One folder per Cloudflare Pages project, each mapped to its own
subdomain via the project's "root directory" setting:

| Folder | Cloudflare Pages root directory | Subdomain |
|---|---|---|
| `www/` | `www` | www.open4dshell.com |
| `foundation/` | `foundation` | foundation.open4dshell.com |

Each folder is a self-contained static site: plain HTML5, one small
stylesheet, no JavaScript, no build step.

## Refreshing foundation/docs/

`foundation/docs/` is a copy of `Resources/Fnd_Shell_Documentation` from
the Foundation repository (f6). It is not generated by this repository;
it is copied in after being built there.

To refresh it:

1. In the Foundation repository, run:
   ```
   node Resources/Fnd_Shell_Documentation/build-current-reference.mjs --check
   ```
   to confirm the generated reference is current.
2. Copy the built `Fnd_Shell_Documentation` output into `foundation/docs/`
   here, replacing the existing contents.
3. Record the source commit hash of the Foundation repository in
   `foundation/docs/DOCS_SOURCE`.
