The installer

Foundation is a component, but parts of it have to live in your database: a small set of methods it calls, and the tables some of its modules keep their data in. It adds none of them without asking. The installer lists what is missing and waits for you to choose Install or Cancel.

This page shows what the installer shows, so you can read it before you open your database.

Running it

  1. Copy Foundation.4dbase into your project's Components/ folder.
  2. Open your database in 4D, in interpreted mode.
  3. Run the method Fnd_Shell_Installer. The installer also opens by itself the first time your code calls Foundation.
  4. Read the list, then choose Install or Cancel.

Install adds everything listed below that your database does not already have. Cancel adds nothing: your database is left untouched and you can simply remove the component. A compiled database is never changed.

After installing, restart the database so the new tables are available and the new methods compile.

What is never changed

Your own code in a hook method is never changed. A Foundation host method whose parameters are out of date is replaced, with the previous code kept below it as a comment.

The hook and host methods are described in chapter 4 of the Developer Guide; chapter 3, Starting fresh, covers a new database from the beginning.
