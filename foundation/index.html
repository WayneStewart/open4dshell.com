Foundation

An application shell component for 4D

Foundation 6.0.0-beta.1, private beta from 1 November 2026. The repository becomes public on 1 December 2026.

Foundation (also known as Foundation Shell) is a reusable application shell component for 4D. It provides menus, windows, toolbars, navigation, input and output forms, find, sort, lists, preferences, localisation, logging, dialogs, passwords, sequence numbers, and a virtual structure layer. You add your own tables and forms; Foundation supplies the application around them.

Foundation was created by Dave Batton in 1993 and developed by Walt Nelson / Nelson Consulting, Inc. from October 2008, including Foundation 5 for 4D v11 with a team of community developers. Wayne Stewart has maintained it since the 4D v16 / 64-bit era. On 11 September 2026 it was assigned to him by deed for release as open source under the MIT licence, with the names of Dave Batton and Walt Nelson kept permanently in the credits, the About box and the method headers.

The beta

Foundation 6 requires 4D 20 LTS or later, on macOS or Windows. Each release ships four builds of the compiled component from one commit, all carrying the same version:

Target4D
20L20 LTS
20R20 R (20 R10)
21L21 LTS
21R21 R (the latest R)

Each target comes as a code-signed, notarised DMG for macOS and a ZIP of the same component for Windows. The compiled component runs on both platforms.

During the beta the source and the builds are in the GitHub repository open4dshell/Foundation-Shell, which is private until 1 December 2026. Private means not yet announced to the world: the code is already under the MIT licence, there is nothing to sign, and the beta is free. To join, send your GitHub username to wayne@open4dshell.com and you will be added with read access. Problems and suggestions go in that repository's Issues; please say which 4D version and which target you used.

Getting started

  1. Download the DMG (macOS) or ZIP (Windows) for your 4D from the GitHub release. SHA-256 checksums are listed with the release.
  2. Install: copy Foundation.4dbase into your project's Components/ folder and reopen the project. For development, the repository itself also works as an interpreted component.
  3. New host? Clone Foundation Product Sales, the demo database, which is public now and runs as soon as it is cloned. Its Fnd_Hook_* and Fnd_Host_* methods are the whole contract between a host and Foundation; copy the ones you need.
  4. Foundation 5 host? Read Release/UPGRADING.md in the repository first. The breaking changes are few and listed: Foundation's own licensing methods are gone, cs.fnd.wnd is no longer published, the separate Logging component is no longer required, and German is DE rather than GR.

Foundation is free under the MIT licence. There is nothing to register and nothing expires.
