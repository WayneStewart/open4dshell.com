Foundation 6 Developer Guide

How to build a database on Foundation, the open-source application shell component for 4D. This replaces the first forty pages of the Foundation 5.4 Developer Reference Manual (2011); the per-method reference that made up the rest of that book is now generated from the method headers and published at https://foundation.open4dshell.com/docs/. The guide is written in plain Markdown so that the web site can render it as its own section, separate from that reference.
