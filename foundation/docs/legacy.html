What This Site Contains

The original manual describes Foundation 5.4 as a 4D v11 SQL-era component-based shell and utility library. This site keeps that legacy content available in a form that is faster to search and easier to navigate from inside the project resources.

The command pages are generated from the manual's language-reference sections. The full manual page preserves the broader chapters, license text, upgrade notes, setup instructions, and historical material.
