Fnd_Find_AddItem

Fnd_Find_AddItem (position; label; method{; ->field{; type}})

Called by the protected "Fnd_Find_Add" routines to add stuff to the arrays.

If the label is blank, the field name will be used.

ParameterTypeDirectionDescription
inPositionLongintinThe position
labelTextinThe label
methodTextinThe method
inFieldPointerinThe field (optional)
inFieldTypeLongintinThe field's type (optional)

labelTextinThe label for the popup item
inPositionLongintinThe position in which to add the first item (optional)

Fnd_Find_AddSeparator

Fnd_Find_AddSeparator ({position})

Adds a separator line to the list of searchable fields.

ParameterTypeDirectionDescription
inPositionLongintinPosition of the separator (optional)

Fnd_Find_AddSubfield

Fnd_Find_AddSubfield (->subfield; field type{; position})

Lets the developer add a subfield to the Find dialog. The field type must be specified because we can't procedurally determine this like we can for fields. If a position isn't specified, the field is added to the end of the list.

ParameterTypeDirectionDescription
fieldPointerinA pointer to the field to add
fieldTypeLongintinThe type of the subfield
inPositionLongintinThe position in which to add the item (optional)

ResultLongintoutThe best object size for the pop-up

Fnd_Find_GetExtraWidth

Fnd_Find_GetExtraWidth --> Number

Returns the extra width needed to display the Find dialog so none of the text in the pop-up menus gets truncated.

Lots of stuff is hard-coded here because we can't get it procedurally. :-(

ParameterTypeDirectionDescription
ResultLongintoutThe extra width required

Fnd_Find_SizeArrayObject

Fnd_Find_SizeArrayObject (->object; alignment) --> Number

Sets the best size for an array based form object based on the contents it displays.

Rather than using BEST OBJECT SIZE, we calculate the size the same way we did before opening the dialog using the Fnd_Find_GetExtraWidth method.

ParameterTypeDirectionDescription
objectPointerinA pointer to the form object
alignmentLongintinThe alignment (side not to move)
ResultLongintoutThe increase in the button size
