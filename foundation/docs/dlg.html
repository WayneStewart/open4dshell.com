Fnd_Dlg_Message

Fnd_Dlg_Message (message text)

Displays a message window.   Stays open until it's called again with a blank string.

Designed to be a replacement for 4D's MESSAGE command.

See also: 4D's own Progress component (Progress New, Progress SET PROGRESS, Progress QUIT), which is the better choice for new code; Fnd_Dlg_Message stays for hosts that already call it.

ParameterTypeDirectionDescription
messageTextinThe message to display

Fnd_Dlg_Request

Fnd_Dlg_Request (msg{; default{; OK button{; Cancel button}}}) --> Text

Displays a Request dialog. Returns the user's response and sets the OK variable.

Use Fnd_Dlg_GetRequest to find out what the user typed.

ParameterTypeDirectionDescription
msgTextinThe message to display
inDefaultTextinThe default response text (optional)
inOkButtonTextinThe OK button text (optional)
inCancelButtonTextinThe Cancel button text (optional)
ResultTextoutText user entered in Request dialog

Fnd_Dlg_SetIcon

Fnd_Dlg_SetIcon ({icon number})

Sets the icon for the upcoming alert. 0 = Default icon (Note) 1 = Note Icon 2 = Warn Icon 3 = Stop Icon

These Foundation constants are available: Fnd_Dlg_NoteIcon = Note Icon Fnd_Dlg_WarnIcon = Warn Icon Fnd_Dlg_StopIcon = Stop Icon

See also Fnd_Dlg_CustomIcon.

ParameterTypeDirectionDescription
inIconNumberLongintinIcon number (optional)

Fnd_Dlg_SetProgress

Fnd_Dlg_SetProgress (to or from{; to})

The developer calls this to set the From and To numbers.

If only one number is passed, the From is assumed to be 1.

ParameterTypeDirectionDescription
inFromLongintinThe ending number if no second parameter or the starting number
inEndingNumberLongintinThe ending number (optional)

Fnd_Dlg_SetRequest

Fnd_Dlg_SetRequest ({default})

Sets up the next dialog to allow the user to enter a value. Optionally sets the default value of the value. Pass "*" as the default value to cause the entry area to display bullets rather than text.

ParameterTypeDirectionDescription
inDefaultTextinThe default value (optional)
