Download

Foundation is a compiled 4D component. The floor is 4D 20 LTS.

Foundation 6.0.0-rc.1

27 November 2026

Contains builds for 4D 20 and 21, LTS and the latest R release, for Mac (DMG) and Windows (ZIP).

Open the download folder on Dropbox

Download the files you need from the folder. Each file name ends with its 4D target: 20L and 21L for the LTS releases, 20R and 21R for the R releases. A checksums file is in the folder too.

Installing

Copy Foundation.4dbase into your project's Components/ folder. Getting started walks through the rest.

Verifying a download

Compare the SHA-256 of the file you downloaded with its line in the checksums file. On macOS run shasum -a 256 <file>; on Windows run certutil -hashfile <file> SHA256.
