Fnd_Test_Assert

Fnd_Test_Assert ($ok_b : Boolean; $message_t : Text)

Records one assertion and writes it to the Fnd_Test log. Use in test methods, Foundation's or a host's, in place of ASSERT. A failure is counted, not raised.

Nothing interactive happens, so a test behaves the same run from the IDE or headlessly under Fnd_FCS_TestRunner. Results are read from the log, or from testResults.json when the runner wrote them.

ParameterTypeDirectionDescription
okBooleaninThe condition being asserted
messageTextinWhat was expected, and what was found

Fnd_Test_End

Fnd_Test_End

Closes a test method and writes the tally to the Fnd_Test log. Call it as the last line of every test method, Foundation's or a host's.

No parameters.
