Fnd_Sort_AddField

Fnd_Sort_AddField (->field{; position})

Lets the developer add a field to the Sort dialog. If a position isn't specified, the field is added to the end of the list.

ParameterTypeDirectionDescription
fieldPointerinA pointer to the field to add
inPositionLongintinThe position in which to add the item (optional)

Fnd_Sort_AddSeparator

Fnd_Sort_AddSeparator ({position})

Adds a separator line to the list of sortable fields.

ParameterTypeDirectionDescription
inPositionLongintinPosition of the separator (optional)

Fnd_Sort_AddTable

Fnd_Sort_AddTable (->table{; position})

Loads the visible, sortable fields for the specified table into an array named Fnd_Sort_Fields_aptr.

ParameterTypeDirectionDescription
tablePointerinA pointer to the table to add
inPositionLongintinThe position in which to add the item (optional)

Fnd_Sort_Direction

Fnd_Sort_Direction ({direction}) --> Longint

Allows the developer to set or get the currently selected sort direction.

If a valid direction is specified, this routine will make it the default direction.

ParameterTypeDirectionDescription
desiredDirectionLongintinThe desired sort direction (optional)
ResultLongintoutThe current sort direction

Fnd_Sort_Display

Fnd_Sort_Display ({->table})

Displays the simple Sort dialog. If the Macintosh Option key or Windows Alt key is down, 4D's Order By editor is displayed instead.

ParameterTypeDirectionDescription
inPointerTablePointerinA pointer to the table to use (optional)

Fnd_Sort_Info

Fnd_Sort_Info (label) --> Text

ParameterTypeDirectionDescription
requestTextinInfo desired ("version" or "name")
ResultTextoutResponse

Fnd_Sort_OrderByEditor

Fnd_Sort_OrderByEditor

Displays the simple Sort dialog. If the Macintosh Option key or Windows Alt key is down, 4D's Order By editor is displayed instead.

No parameters.

Fnd_Sort_SelectedField

Fnd_Sort_SelectedField ({->field}) --> Pointer

Allows the developer to set or get the currently selected sort field.

If a field pointer is specified, this routine will make it the default selection if it's available in the list. If not, nothing changes.

ParameterTypeDirectionDescription
desiredFieldPointerinThe field to default to (optional)
ResultPointeroutThe selected sort field
