Fnd_Find_AddMultiField

Fnd_Find_AddMultiField (->array of field ptrs; label{; position})

Lets the developer add one item for searching multiple fields.

ParameterTypeDirectionDescription
fieldPointerinA pointer to an array of pointers
labelTextinThe label for the popup item
inPositionLongintinThe position in which to add the first item (optional)

Fnd_Find_AddSeparator

Fnd_Find_AddSeparator ({position})

Adds a separator line to the list of searchable fields.

ParameterTypeDirectionDescription
inPositionLongintinPosition of the separator (optional)

Fnd_Find_AddSubfield

Fnd_Find_AddSubfield (->subfield; field type{; position})

Lets the developer add a subfield to the Find dialog. The field type must be specified because we can't procedurally determine this like we can for fields. If a position isn't specified, the field is added to the end of the list.

ParameterTypeDirectionDescription
fieldPointerinA pointer to the field to add
fieldTypeLongintinThe type of the subfield
inPositionLongintinThe position in which to add the item (optional)

Fnd_Find_Now ("Query" or "Query Selection")
