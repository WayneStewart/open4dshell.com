Fnd_SVG_GetStringHeight

Fnd_SVG_GetStringHeight (text; font; size {; style}) --> height

Returns the height of text in pixels for the supplied font settings.

4D constants may be used for the style parameter.

ParameterTypeDirectionDescription
inTxtTextinThe text to measure
txtTextinThe font used to display the text
lonIntegerinThe font size
inLonIntegerinThe font style (optional)
ResultRealoutThe text height in pixels
