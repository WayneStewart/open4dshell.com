Fnd_Menu_MenuBarName

Fnd_Menu_MenuBarName ({menu name{; Window menu number}}) --> Text

Allows the developer to specify the menu bar to display the next time the menu bar is displayed by a Foundation component.

If a blank name is specified, the default Foundation menu bar name is restored.

You can also specify an optional number for the Window menu to use if you want to add a Window menu to a non-Foundation database.

ParameterTypeDirectionDescription
inMenuNameTextinThe menu bar name (optional)
inWindowMenuNumberLongintinThe number of the Window menu (optional)
ResultTextoutThe menu bar name to use next

Fnd_Menu_ViewOptions

Fnd_Menu_ViewOptions

Supports the View Options function for Fnd_Out. Opens the single, shared View Options palette process (Fnd_Out_ViewOptionsProcess) if it isn't already running, or brings its window to front if it is - never a second palette. The palette serves whichever list window is front, retargeting through Fnd_Out_ViewOptionsFront as focus moves between Foundation windows; this method only needs to get it open or forward.

Runs with Form bound to the Fnd_Out form, since it's reached from Fnd_Out's own menu bar while its window is front - the same context Fnd_Menu_Sort relies on to reach Form.listData directly.

No parameters.
