Download

Each release ships the compiled component for four 4D targets: as a code-signed, notarised DMG for macOS, and as a ZIP of the same component for Windows. The floor is 4D 20 LTS. Pick the file that matches the 4D your host database runs on.

Verifying a download

Compare the SHA-256 of the file you downloaded with the value above. On macOS run shasum -a 256 <file>; on Windows run certutil -hashfile <file> SHA256.

Installing

Copy Foundation.4dbase into your project's Components/ folder. Getting started walks through the rest.
