aaa_Test_Fnd

aaa_Test_Fnd

A scratch method kept for trying things out from a host. The body is deliberately commented out, so calling it does nothing.

It is Shared, so a host can reach it, and it has a typing entry in Compiler_Fnd_MethodParameters for the object parameter its commented #DECLARE takes. Uncomment, experiment, and comment out again — do not build anything on it.

No parameters.
