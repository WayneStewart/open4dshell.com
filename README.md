# open4dshell.com

Source for the Open 4D Shell static site. Wayne Stewart's home for
open-source 4D components since 2010; Foundation is the main project.

## Layout

One folder per Cloudflare Pages project, each mapped to its own
subdomain via the project's "root directory" setting:

| Folder | Cloudflare Pages root directory | Subdomain |
|---|---|---|
| `www/` | `www` | www.open4dshell.com |
| `foundation/` | `foundation` | foundation.open4dshell.com |

Each folder is a self-contained static site: plain HTML5, one small
stylesheet, no JavaScript, no build step.

## Refreshing foundation/docs/

`foundation/docs/` is a copy of `not res/Fnd_Shell_Documentation` from
the Foundation repository (f6); earlier it was `Resources/Fnd_Shell_Documentation`. It is not generated by this repository;
it is copied in after being built there.

To refresh it, run `scripts/refresh-docs.sh /path/to/foundation-repo`,
which performs these steps:

1. In the Foundation repository, run the generator's `--check` to confirm
   the generated reference is current (it warns rather than stops if the
   check itself cannot run).
2. Copy the built `Fnd_Shell_Documentation` output into `foundation/docs/`
   here, replacing the existing contents.
3. Copy `LICENSE` and `PROVENANCE.md` from the Foundation repository root.
4. Record the source commit hash of the Foundation repository in
   `foundation/docs/DOCS_SOURCE`.
